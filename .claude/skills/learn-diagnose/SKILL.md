# 摸底

目标是找到起点，不是考试。**不要提时长、不要给时间压力。**

两种摸底共用同一个收尾：先把判断直接说给学习者 → 他决定跳过哪些、从哪开始 → 再统一记录和改进度（见“收尾”）。**收尾之前不改任何 issue。**

## 全课摸底

备课完成后做一次，覆盖全部单元。

1. 先问一句背景：学过哪些相关内容、学这门课的目的。
2. 读 `course/SYLLABUS.md`。逐个单元：
   - 学习者说这个单元完全没学过 → 不问，判断记为“没见过”。
   - 否则读该单元核心关卡卡片的“常见误区”，出 **1 道能暴露误区的诊断题**（答对和“蒙对”要能区分，例如要求简短说明理由）。
   - 答得好 → 再出 1 道该单元较难的综合题。
   - 答错 → 往前追问，找到第一个出问题的关卡。
3. 一次一题，等回答。答错时只用一两句说清正确思路，不展开教学。

## 单元摸底

某单元开学前做；同一单元可以重做（只追加记录，不动已掌握的关，除非学习者要改）。

1. 准备（不用跟学习者说过程）：
   - 读 `course/SYLLABUS.md` 中该单元的表格和各关卡片的“核心问题”“常见误区”。
   - `python3 scripts/tracker.py show <单元号>-boss`：看全课摸底和以往单元摸底的汇总。
   - 对该单元各关 `tracker.py show <id>`：看全课摸底记录、上一单元 boss 留下的“前置题”记录、已有学习记录。**已经测过且结论清楚的点不再出题**；已掌握的关不出题。
2. **概念题 5–8 道，一次性发出**，让学习者一条消息回完（如“1B 2 没见过 3 是说……”）：
   - 每题对应一关的关键概念或名词，形式是选择、判断或一句话问答，考的是“见过没有、理解对不对”，不考计算。
   - 选择题都带一个“没见过 / 不确定”选项；干扰项来自卡片的“常见误区”；正确选项位置随机。
   - 题目标上对应关卡 id，方便记录。
3. 看完回答，**最多再出 1 道动手题**，放在本单元最核心、且概念题答得还不错的那一关，用来分辨“见过”和“会用”。概念题已经大面积“没见过”就不出。
4. 判完只用一两句说要点，不展开教学。

## 收尾（两种摸底相同）

1. **先说给学习者**：逐关给判断——熟悉 / 见过但模糊 / 不会 / 没见过（没测到的关写“未测”），附一句依据；再给建议：哪些关可以跳过、从哪一关开始。
   摸底时还没正式学，答错只说明“不会 / 没见过”：**不说“薄弱点”“有误区”**。薄弱点留给正式学过（闯关、测试）后仍反复出错的情形。
2. **等他回复**：跳过哪些、从哪开始，以他的决定为准。
3. **按他的决定记录和改进度**（每个涉及的单元）：

   ```bash
   python3 scripts/tracker.py clear-labels <单元号>      # 清掉该单元旧的摸底标注
   python3 scripts/tracker.py set <id> done              # 他决定跳过的关
   python3 scripts/tracker.py label <id> startpoint      # 他决定开始学的那一关
   ```

   不再使用 `skip` 标注；AI 的判断只写进记录。

4. 出过题的关卡，各写一条简短评论：

   ```bash
   python3 scripts/tracker.py comment <id> <<'EOF'
   ### 单元摸底 2026-11-05        （全课摸底就写“全课摸底”）
   **题**：……
   **回答要点**：……
   **判断**：熟悉 / 见过但模糊 / 不会 / 没见过（……）
   **学习者决定**：跳过 / 从这开始 / 正常学
   EOF
   ```

5. 在每个涉及单元的 boss issue 下写一条汇总（全课摸底就每个单元各写一条）：

   ```bash
   python3 scripts/tracker.py comment <单元号>-boss <<'EOF'
   ### 单元摸底 2026-11-05        （或“全课摸底”）
   **逐关判断**：02-01 熟悉；02-02 见过但模糊；02-03 没见过；02-04 不会；……（完全没学过的单元写“学习者说完全没学过”）
   **学习者决定**：跳过 02-01、02-02；从 02-03 开始
   EOF
   ```

6. 一句话说下一步：单元摸底后可以直接在本对话学“从这开始”那一关（转入 `learn-level`），也可以以后开新对话再学，结果都已保存。全课摸底后建议开新对话开始学。
