# 测试

## 准备

1. 确定对象：关卡 id 或 `<单元号>-boss`。`python3 scripts/tracker.py show <id>` 读卡片与历史评论。
   - boss：issue 正文列出了本单元关卡，逐一读这些卡片的通关标准和常见误区，以及各关历史评论里的错因。
2. 出题原则：
   - **不重复**历史评论里出过的题；针对以前的错因出**变式题**。
   - 题型层次：计算 → 概念判断（选择题的干扰项来自“常见误区”，正确选项位置随机）→ 解释为什么 → 迁移到新情境。
   - 单关 4–5 题、覆盖每条通关标准；boss 6–8 题，以跨关卡综合与迁移为主。
   - boss 另加 **1–2 道前置题**：在 `course/levels/` 里找下一单元中 `prereqs` 引用了本单元关卡的卡片，挑下一单元最依赖的本单元内容出题（下一单元已全部掌握或没有下一单元就不出）。出题前先 `show <单元号>-boss` 看本单元摸底汇总，针对摸底暴露的薄弱点出综合题。
   - 难度贴近素材里的例题与习题。
   - 题面照 `../learn-level/SKILL.md` 的“题面规矩”：一题一问、不自加小问、不写思路引导、自包含。

## 进行

- 一次一题，等他作答后再判。不给提示，除非他要求（要求了就记下“有提示”）。
- 判完给简短讲解；答错时先讲清楚，再**换一种形式**重问同一要点，第二次答对记为“纠正后掌握”。

## 收尾

1. 写记录：

   ```bash
   python3 scripts/tracker.py comment <id> <<'EOF'
   ### 测试 2026-11-05（4/5）
   1. （题目全文）—— ✅
   2. （题目全文）—— ❌ 错因：…… → 变式重问 ✅
   **薄弱点**：……
   **建议**：……
   EOF
   ```

   boss 测试中暴露的某关问题，也在那一关的 issue 下补一条简短评论。

   前置题的结果记在**下一单元**依赖它的那一关下面，供那个单元的单元摸底参考、避免重复出题：

   ```bash
   python3 scripts/tracker.py comment <下一单元的关卡 id> <<'EOF'
   ### boss 前置题 2026-11-05（来自 <单元号>-boss）
   **题**：……
   **结果**：✅ / ❌ 错因：……
   EOF
   ```

2. 写笔记：照 `../learn-level/note.md` 把这次每道题（不论对错）、全部手写照片、关键推导和可视化、方法小结收进 `tracker.py note <id>`；boss 测试写在 `<单元号>-boss` 的笔记里。没出过题才不写；全对也要写，每题带题面和关键步骤。

3. 给建议但**不自己改状态**：例如“第 2、4 题暴露 δ 的选取还不熟，建议把 02-03 改成待复习，要改吗？”他同意才 `tracker.py set <id> review`（或 `done`）。boss 他认为过了就 `set <单元号>-boss done`。
