# 写笔记

笔记写给学习者自己回看，和学习记录（写给导师）分开、不重复。闯关、单关测试、boss 测试结束时写；摸底不写。

## 收什么

- **错题**：只写做错过的题（含“纠正后掌握”）：题目、他当时的思路、错在哪、正确过程。一次做对的题不进笔记。
- **手写照片**：学习者这次上传的手写演算全部收进去，放在对应错题下面。
- **可视化**：只收讲清核心概念、或帮他纠正错误的那几张；过程中的草图、选项卡片、单纯的提问卡不收。
- **感悟**：只在他说“记下来”“把这个加到笔记”时写，用他自己的话，你只排版。

什么都没有（全做对、没图、没让记）→ 不写这次笔记。不用问他，结束时自动收。

## 可视化转图片

把那张可视化的 HTML 代码原样存进临时文件，截成 PNG：

```bash
python3 scripts/snap.py /tmp/viz-1.html /tmp/viz-1.png
```

片段里的 `$...$` 会被 KaTeX 渲染。截完用 Read 看一眼图对不对。

## 排版

写给“你”（学习者），口语化、完整句子，不用“起点理解：”“判断：”这类压缩标签。数学用 LaTeX：行内 `$...$`，推导和结论单独成行用

```
$$
...
$$
```

不用宽表格（手机上会挤）。图片用 `{{img1}}` `{{img2}}` 占位，按 `--image` 的顺序替换。模板：

```markdown
## 闯关 2026-11-05

### ❌ 判断 $f$ 在 $x=2$ 处是否连续

$$
f(x)=\begin{cases}\dfrac{x^2-x-2}{x-2}, & x\ne 2\\ 1, & x=2\end{cases}
$$

**你当时的思路**：分子能约掉，极限是 3，所以连续。

{{img1}}

**错在哪**：极限存在只是三条里的第二条，还要和 $f(2)$ 比——$3\ne 1$，所以是可去间断。

**正确过程**：……

---

### 💡 你的感悟

> 连续 = 函数值“恰好等于”你一路走过去要到的那个值。

{{img2}}
```

标题用“闯关”“测试”“boss 测试”加日期。

## 发出去

```bash
python3 scripts/tracker.py note <id> --file /tmp/note.md --image 手写.jpg --image /tmp/viz-1.png \
  --intro "一句人话说清这关在学什么"
```

- 这关还没有笔记 issue 时会自动创建；`--intro` 只在创建时写进正文，之后可省略。
- 学习者上传的图片，路径就是聊天里那张图的本地文件路径。
- boss 测试的笔记写在 `<单元号>-boss` 下；某题明显属于某一关时，在那一关的笔记里补一条一行的链接指过去（`tracker.py note <关卡id>`，正文只写“boss 测试里有一道这关的题：<评论链接>”）。
