# 写笔记

笔记写给学习者自己隔很久回看，和学习记录（写给导师）分开、不重复。闯关、单关测试、boss 测试结束时写；摸底不写。

**写详细，宁多勿漏。** 学习者要的是一份回看时不用翻聊天、不用问导师就能完整复习这一关的笔记：这关做过的题、他自己的推导和手写、导师讲清的关键点，都在里面。下面“收什么”是最低要求，不是上限。

## 收什么

1. **这关做过的每一道题**（动手题、检查题、讲解中途出的小题都算），不论对错：
   - **完整题面**：题干、已知条件、每个小问都抄进笔记（LaTeX），不能只写标题或“第 3 题”。读图题（函数图像、表格、几何图）把题图截成 PNG 一起放上去。
   - **他当时的思路和结果**：做对写 ✅，做错写 ❌，纠正后掌握写 ✅（纠正后）。
   - **做错的题再写**：错在哪、错因归类、正确过程。做对的题写关键步骤，不用重复他已经对的细节。
2. **手写照片：他这次上传的每一张都收进去**，不论对错，放在对应那道题下面。发出前数一遍聊天里的图，`--image` 的数量要对得上。
3. **他自己推出来的推导、公式来历**（例如“由定义推某个公式”）：完整写出来，用他的思路，不是导师的标准答案。
4. **方法与结论小结**：这关要记住的方法、步骤、公式、四种情况对照、易混点，单独成节，写成可以直接背的形式。导师在讲解中补的、素材没讲的内容也收，标明“补充”。
5. **可视化**：讲清核心概念、帮他纠正错误的都收。聊天里卡片里的内容，要么截图（见下），要么直接用 LaTeX 在笔记里重写成文字推导，两者选稳的。纯提问卡、选项卡不收。
6. **感悟**：只在他说“记下来”“把这个加到笔记”时写，用他自己的话，你只排版。

什么都没有才不写：这关没出过任何题、没有手写、没有推导可收。有任何一道题就写。不用问他，结束时自动收。

## 可视化转图片

把那张可视化的 HTML 代码原样存进临时文件，截成 PNG：

```bash
python3 scripts/snap.py /tmp/viz-1.html /tmp/viz-1.png
```

片段里的 `$...$` 会被 KaTeX 渲染。截完用 Read 看一眼图对不对。不方便截（没存代码、没装 Chrome）就用 LaTeX 重写。

## 排版

写给“你”（学习者），口语化、完整句子，不用“起点理解：”“判断：”这类压缩标签。数学用 LaTeX：行内 `$...$`，推导和结论单独成行用

```
$$
...
$$
```

不用宽表格（手机上会挤；3 列以内的小对照表可以）。图片用 `{{img1}}` `{{img2}}` 占位，按 `--image` 的顺序替换。

## 发出前自查

1. 聊天里学生上传了几张手写，`--image` 里就有几张，一张不少。
2. 这关出过几道题，笔记里就有几节，每节都有完整题面。
3. 每道错题都有“错在哪”和“正确过程”。
4. 有没有他自己的推导、讲解中的补充、易混点还没写进“这关要记住的”。
5. 数学全是 LaTeX，没有 Unicode 拼的公式。

## 发出去

```bash
python3 scripts/tracker.py note <id> --file /tmp/note.md --image 手写1.jpg --image 手写2.jpg \
  --intro "一句人话说清这关在学什么"
```

- 这关还没有笔记 issue 时会自动创建；`--intro` 只在创建时写进正文，之后可省略。
- 学习者上传的图片，路径就是聊天里那张图的本地文件路径；HEIC 先用 `sips -s format jpeg` 转成 JPEG。
- boss 测试的笔记写在 `<单元号>-boss` 下；某题明显属于某一关时，在那一关的笔记里补一条一行的链接指过去（`tracker.py note <关卡id>`，正文只写“boss 测试里有一道这关的题：<评论链接>”）。
