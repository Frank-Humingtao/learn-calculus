## 范围
- 讲：$F=ma$、单位 N 与 J；常力 $W=Fd$；变力 $W=\int_a^bf(x)\,\mathrm dx$（定义 4）；质量（要乘 $g$）与重量（本身是力）的区别；胡克定律 $f(x)=kx$；缆绳问题（各段移动距离不同）；抽水问题（体积 → 质量 → 力 → 距离 → 功）
- 不讲：气体膨胀做功 $\int P\,\mathrm dV$、功能原理、万有引力做功（练习 29–35，选做）

## 通关标准
1. 能用“小区间上力近似不变”解释为什么变力做功是 $\int_a^bf(x)\,\mathrm dx$，并区分给质量与给重量两种情形
2. 能用胡克定律由已知条件求 $k$，并以伸长量为积分限计算弹簧做功
3. 能对缆绳类问题切分并说清每段的力和移动距离，列式计算
4. 能对抽水问题按“体积 → 质量 → 力 → 距离”写出一层水的功并积分

## 常见误区
- 给的是重量（N）还乘 $g$；给的是质量（kg）却忘乘 $g$
- 弹簧积分限写成弹簧总长而不是伸长量；cm 没换成 m
- 缆绳问题直接用“总重 × 总长”；例 4(b) 中下段的移动距离应是常数 6，而不是 $x$
- 抽水问题积分限从 0 开始（水没装满）；层半径随坐标增大而减小的关系写反；漏掉密度或 $g$
