### 积分技巧

利用微积分基本定理，如果已知一个函数的原函数，即其不定积分，我们可以求其定积分.下面总结了到目前为止我们学习过的一些最重要的不定积分.

$$
\int k \mathrm{d} x = k x + C
$$

$$
\int \sin x \mathrm{d} x = - \cos x + C
$$

$$
\int \tan x \mathrm{d} x = \ln | \sec x | + C
$$

$$
\int x ^ {n} \mathrm{d} x = \frac {x ^ {n + 1}}{n + 1} + C \quad (n \neq - 1)
$$

$$
\int \cos x \mathrm{d} x = \sin x + C
$$

$$
\int \cot x \mathrm{d} x = \ln | \sin x | + C
$$

$$
\int \sec^ {2} x \mathrm{d} x = \tan x + C
$$

$$
\int \frac {1}{x ^ {2} + a ^ {2}} \mathrm{d} x = \frac {1}{a} \tan^ {- 1} \left(\frac {x}{a}\right) + C
$$

$$
\int \frac {1}{x} \mathrm{d} x = \ln | x | + C
$$

$$
\int \csc^ {2} x   \mathrm{d} x = - \cot x + C
$$

$$
\int \frac {1}{\sqrt {a ^ {2} - x ^ {2}}} \mathrm{d} x = \sin^ {- 1} \left(\frac {x}{a}\right) + C, a > 0
$$

$$
\int \mathrm{e} ^ {x} \mathrm{d} x = \mathrm{e} ^ {x} + C
$$

$$
\int \sec x \tan x   \mathrm{d} x = \sec x + C
$$

$$
\int \sinh x   \mathrm{d} x = \cosh x + C
$$

$$
\int b ^ {x} \mathrm{d} x = \frac {b ^ {x}}{\ln b} + C
$$

$$
\int \csc x \cot x   \mathrm{d} x = - \csc x + C
$$

$$
\int \cosh x   \mathrm{d} x = \sinh x + C
$$
