## 2. Jerison 教学思路主线

开场先更正上讲末尾：\(\int\sin x\cos x\,dx\) 两答 \(\frac12\sin^{2}x+c_{1}\) 与 \(-\frac12\cos^{2}x+c_{2}\) 要相等时，相减得 \(c_{1}-c_{2}+\frac12=0\)，故 \(c_{1}-c_{2}=-\frac12\)（口播曾写错过符号；网上材料会改）。随即宣布：**第二单元「微分的应用」最后一天**，引入最有趣主题之一——**微分方程（differential equations）**；完整课程是 18.03，今天只教一种与**微分记号**严丝合缝的技巧。

先钉死最简型
\[
\frac{dy}{dx}=f(x)\quad\Rightarrow\quad y=\int f(x)\,dx,
\]
视为「已解决」；求反导数目前只有换元（及变体 advanced guessing）。真正第一道新题是 Example 2：
\[
\Bigl(\frac{d}{dx}+x\Bigr)y=0\quad\text{即}\quad\frac{dy}{dx}+xy=0
\]
——量子力学里的**湮灭算符（annihilation operator）**（改号即产生算符），控制谐振子基态；解虽有花哨名号，方程本身简单。改写 \(\frac{dy}{dx}=-xy\)：变化率同时依赖 \(x\) 与 \(y\)。关键一步用微分：除以 \(y\)、乘以 \(dx\)，
\[
\frac{dy}{y}=-x\,dx
\]
——左右各只含一个变量。对两边取反导数（莱布尼茨记号）得 \(\ln|y|=-x^{2}/2+c\)，指数化 \(y=ae^{-x^{2}/2}\)。验证链式法则；点明这是**正态分布**曲线，并与概率 / 量子位置解释挂钩。

随即抽出**分离变量一般法**：当 \(\frac{dy}{dx}=f(x)g(y)\) 时，写成 \(h(y)\,dy=f(x)\,dx\)（\(h=1/g\)），积分得隐式 \(H(y)=F(x)+c\)，必要时 \(y=H^{-1}(F(x)+c)\)。补一串技术备注：绝对值与 \(y<0\)；除以 \(y\) 漏掉平凡解 \(y=0\)；两边各写一个常数是冗余（合并为一个 \(c\)）；指数化后相加常数变成相乘常数；最简型 Example 1 也可用「把 \(dx\) 移过去」看成分离变量。

几何 Example 3：切线斜率 = 原点射线斜率的两倍 \(\Rightarrow\frac{dy}{dx}=2\frac{y}{x}\)；分离得 \(y=ax^{2}\)（抛物线族）。警告：方程在 \(x=0\) 无定义，跨过原点时解可不唯一，宜看成从原点发出的射线而非完整抛物线。Example 4：与这些抛物线正交的曲线——斜率取负倒数 \(\frac{dy}{dx}=-\frac{x}{2y}\)；分离得椭圆族；显式只取上半或下半（椭圆不是函数），且 \(y=0\) 处斜率竖直、解终止——与分母中的 \(y\) 一致。

末段 Exam 2 复习提示：通常最难、发讲义标明六类题型（与去年同型），单元主题是「导数（或二阶导数）信息告诉我们 \(f\) 本身」——ODE 与开场近似一脉相承。

整条线：**更正上讲常数差 → 引入 ODE / 18.03 → 最简反导数型 → 湮灭算符例 + 分离变量 → 一般法与常数备注 → 几何抛物线 → 正交椭圆 → Exam 2 范围**。

## 5. 课上完整推导

### 5.1 最简型

\[
\frac{dy}{dx}=f(x)\quad\Rightarrow\quad y=\int f(x)\,dx.
\]

（分离写法：\(dy=f(x)\,dx\)，两边积分同一结果。）

### 5.2 Example 2：\(\frac{dy}{dx}=-xy\)

分离：
\[
\frac{dy}{y}=-x\,dx.
\]
积分（先 \(y>0\)）：
\[
\ln y=-\frac{x^{2}}{2}+c,\qquad y=e^{c}e^{-x^{2}/2}=Ae^{-x^{2}/2}.
\]
带绝对值：\(\ln|y|=-x^{2}/2+c\) ⇒ \(y=\pm Ae^{-x^{2}/2}\)；另加平凡解 \(y\equiv0\)。合写
\[
y=ae^{-x^{2}/2}\quad(a\in\mathbb{R}).
\]
验证：\(\frac{d}{dx}\bigl(ae^{-x^{2}/2}\bigr)=a(-x)e^{-x^{2}/2}=-xy\)。

初值例：\(y(0)=3\) ⇒ \(a=3\)，\(y=3e^{-x^{2}/2}\)。

### 5.3 分离变量一般法

若 \(\dfrac{dy}{dx}=f(x)g(y)\)，令 \(h=1/g\)，则
\[
h(y)\,dy=f(x)\,dx,\qquad H(y)=F(x)+c,
\]
其中 \(H' =h\)，\(F'=f\)。显式（若可求逆）：\(y=H^{-1}(F(x)+c)\)。

只需一个任意常数（两边各写一个可合并）。指数化等非线性步骤后，常数可不复是相加形式。

### 5.4 Example 3：\(\frac{dy}{dx}=2\frac{y}{x}\)

\[
\frac{dy}{y}=\frac{2\,dx}{x},\qquad\ln|y|=2\ln|x|+c,\qquad y=ax^{2}.
\]
验证：\(\frac{d}{dx}(ax^{2})=2ax=\dfrac{2(ax^{2})}{x}=\dfrac{2y}{x}\)。

注意：右端在 \(x=0\) 无定义；跨原点解曲线可不唯一。

### 5.5 Example 4：正交于抛物线

抛物线斜率 \(2y/x\)，正交斜率
\[
\frac{dy}{dx}=-\frac{1}{2y/x}=-\frac{x}{2y}.
\]
分离（课上形式）：
\[
2y\,dy=-x\,dx\quad\Rightarrow\quad y^{2}=-\frac{x^{2}}{2}+c\quad\Rightarrow\quad\frac{x^{2}}{2}+y^{2}=c
\]
（\(c>0\)；写 \(c=a^{2}\)）。椭圆：水平半轴 \(\sqrt{2}\,a\)，竖直半轴 \(a\)。显式
\[
y=\pm\sqrt{a^{2}-\frac{x^{2}}{2}}
\]
（上半 / 下半各一解）。\(y=0\) 时斜率竖直，解终止。
