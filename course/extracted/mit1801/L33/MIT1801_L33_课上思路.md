## 2. Jerison 教学思路主线

本课先**收完上堂留下的第二类反常积分**（有限点奇点），用 \(p\)-幂近 0 的敛散、与无穷远处 \(p\)-幂的对照图、以及中间奇点 \(\int_0^\infty dx/(x-3)^2\) 把「红／绿」直觉钉牢；再正式转入 Unit 5 的**倒数第二主题——无穷级数**（明天才是幂级数）。

第二类开场：定义 \(\int_0^1 f=\lim_{a\to0^+}\int_a^1 f\)；收敛＝极限有限。三典例：\(\int_0^1 x^{-1/2}=2\)（收敛且可求值）；\(\int_0^1 dx/x\) 发散（\(\ln0^+=-\infty\)）；一般 \(\int_0^1 x^{-p}\,dx\) 在 \(p<1\) 收敛、\(p\ge1\) 发散——**分界仍是 \(1/x\)，但与无穷远处相反**。板书对照谱：近 0 时 \(x^{-1/2}\ll x^{-1}\ll x^{-2}\)（越大越坏）；\(x\to\infty\) 则反过来。结合 \(y=1/x\)、\(1/\sqrt{x}\)、\(1/x^2\) 的「一切两半」图：两端皆散／近 0 收敛而尾散／近 0 散而尾敛。末例 \(\int_0^\infty dx/(x-3)^2\) 拆 \(0\to5\)+\(5\to\infty\)：奇点处像 \(1/x^2\)（散）＋尾部有限 ⇒ 整体发散——呼应上堂 \(\int_{-1}^{1}dx/x^{2}\) 的荒谬负值。

切入级数：最重要的几何级数；先用 \(1+\tfrac12+\tfrac14+\cdots=2\) 数轴图（芝诺／时间连续统插曲），再一般 \(1+a+a^2+\cdots=1/(1-a)\)（仅 \(|a|<1\)）。边界反例：\(a=1\)（\(\infty=\infty\) 看似「半对」）、\(a=-1\)（振荡、公式给 \(1/2\)）、\(a=2\)（左无穷右 \(-1\)，数论里可另赋义）——一律标红、排除。

系统记号：部分和 \(S_N=\sum_{n=0}^{N}a_n\)，级数 \(=\lim S_N\)；极限存在（有限）⇒ 收敛。例：\(\sum 1/n^{2}\) 收敛（欧拉 \(\pi^{2}/6\)）、\(\sum 1/n^{3}\) 收敛但无初等闭式（近年证无理）；强调 \(\sim\) 只表「同类型敛散问题」，真正相似的是 \(1/n^{p}\) 与 \(1/x^{p}\)。谐波级数用 \(\Delta x=1\) 的上／下黎曼和夹住：\(\ln N<S_N<1+\ln N\) ⇒ 发散且增速如对数。一般**积分比较**：\(f>0\) 递减 ⇒ \(\sum f(n)\) 与 \(\int_1^\infty f\) 同敛散，且差 \(<f(1)\)。**极限比较**：\(f\sim g\)（\(f/g\to1\)）⇒ 同敛散；例 \(\sum 1/\sqrt{n^{2}+1}\) 散、\(\sum 1/\sqrt{n^{5}-n^{2}}\) 敛。收尾：积木悬伸预告（下次用谐波发散做物理演示）。

整条线：**第二类定义／\(p\)-幂近 0 → 近 0 vs \(\infty\) 对照图 → 中间奇点陷阱 → 几何级数与发散边界 → 部分和定义 → \(p\)-级数与欧拉 → 谐波＋黎曼夹逼 → 积分比较 → 极限比较 → 积木预告**。

## 5. 课上完整推导

### 5.1 第二类反常积分定义

\[
\int_{0}^{1}f(x)\,dx
:=\lim_{a\to0^{+}}\int_{a}^{1}f(x)\,dx.
\]

极限存在且有限 ⇒ 收敛；否则发散。

### 5.2 近 0 的 \(p\)-幂

\[
\int_{0}^{1}x^{-1/2}\,dx
=2x^{1/2}\Big|_{0}^{1}=2
\quad\text{（收敛）}.
\]

\[
\int_{0}^{1}\frac{dx}{x}
=\ln x\Big|_{0^{+}}^{1}
=0-(-\infty)=+\infty
\quad\text{（发散）}.
\]

一般：\(\displaystyle\int_{0}^{1}x^{-p}\,dx=\dfrac{1}{1-p}\)（\(p<1\)）；**\(p\ge1\) 发散**。

对照（与 \(x\to\infty\) 相反）：近 0 时 \(x^{-1/2}\) 最小、\(x^{-1}\) 居中、\(x^{-2}\) 最大；分界仍是 \(1/x\)。

### 5.3 中间奇点

\[
\int_{0}^{\infty}\frac{dx}{(x-3)^{2}}
=\int_{0}^{5}+\int_{5}^{\infty}.
\]

近 \(x=3\) 同 \(1/u^{2}\)（\(u=x-3\)）⇒ 发散；尾部收敛。整体发散。

### 5.4 几何级数

具体：\(1+\tfrac12+\tfrac14+\cdots=2\)（数轴每步到距 2 之半）。

一般（\(|a|<1\)）：
\[
1+a+a^{2}+\cdots=\frac{1}{1-a}.
\]

\(a=\pm1\)、\(|a|>1\) 皆发散（本课不取数论赋义）。

### 5.5 级数定义

\[
S_N=\sum_{n=0}^{N}a_n,\qquad
\sum_{n=0}^{\infty}a_n:=\lim_{N\to\infty}S_N.
\]

极限有限 ⇒ 收敛；否则发散。

### 5.6 谐波级数与黎曼夹逼

上和（\(\Delta x=1\)）：
\[
\int_{1}^{N}\frac{dx}{x}
\le 1+\frac12+\cdots+\frac{1}{N-1}
\le S_N
=\sum_{n=1}^{N}\frac1n.
\]
左＝\(\ln N\to\infty\) ⇒ \(S_N\to\infty\)（发散）。

下和：
\[
\frac12+\cdots+\frac1N
=S_N-1
\le\int_{1}^{N}\frac{dx}{x}=\ln N
\implies
S_N\le1+\ln N.
\]

合并：
\[
\ln N < S_N < 1+\ln N.
\]

### 5.7 积分比较

若 \(f>0\) 递减，则
\[
\Bigl|\sum_{n=1}^{\infty}f(n)-\int_{1}^{\infty}f(x)\,dx\Bigr|<f(1),
\]
故 \(\sum f(n)\) 与 \(\int_1^{\infty}f\) **同敛或同散**。

特别地 \(\sum n^{-p}\)：\(p\le1\) 发散，\(p>1\) 收敛。

### 5.8 极限比较

若 \(f/g\to1\)（\(n\to\infty\)，\(g>0\)），则 \(\sum f\) 与 \(\sum g\) 同敛散。

例：\(1/\sqrt{n^{2}+1}\sim1/n\) ⇒ 发散；  
\(1/\sqrt{n^{5}-n^{2}}\sim n^{-5/2}\)（\(n\ge2\)）⇒ 收敛。
