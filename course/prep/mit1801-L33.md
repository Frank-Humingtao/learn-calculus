## 第二类反常积分：近 0 的 $p$-幂  [00:15–04:07]（t=15–247）
- 概念：$\int_0^1 f=\lim_{a\to0^+}\int_a^1 f$；极限有限 ⇒ 收敛。
- 关键推导/例题：$\int_0^1x^{-1/2}dx=2$（t=126–176）；$\int_0^1\frac{dx}x=0-(-\infty)=\infty$（t=177–220）；一般 $\int_0^1x^{-p}dx=\frac1{1-p}$（$p<1$），$p\ge1$ 发散（t=221–247）。（讲义对应：L32 讲义 Improper Integrals of the Second Type）

## 近 0 与近 $\infty$ 的对照图  [04:08–09:21]（t=248–561）
- 概念：近 0 时 $x^{-1/2}<x^{-1}<x^{-2}$（越大越坏），近 $\infty$ 时顺序反过来；两端的分界都是 $1/x$，但方向相反。
- 关键推导/例题：$y=1/x$ 两端面积都无限；$1/\sqrt x$ 近 0 面积 2、尾部无限；$1/x^2$ 尾部有限、近 0 无限（t=361–561）。
- 讲法特点：板书把发散的情形圈红框，一张图同时比较两类反常积分——斯图尔特是分开讲的。
- 学生可能的误区：把无穷区间的结论（$p>1$ 收敛）照搬到近 0 的情形。

## 中间奇点：$\int_0^\infty\frac{dx}{(x-3)^2}$  [09:22–14:17]（t=562–857）
- 关键推导/例题：拆成 $\int_0^5+\int_5^\infty$；$x=3$ 处像平移的 $1/x^2$（发散），尾部收敛 ⇒ 整体发散；粗心求原函数会得到负数。
- 学生可能的误区：t=718 学生问“为什么整体发散”——总面积 = 两段之和，含无限段就无限；t=756 学生问“扫一眼积分该看哪里”——检查 $\pm\infty$ 和每个奇点，逐点判断；$dx/x^n$（$n=1,2,\dots$）跨奇点一律发散，平方根型可能收敛。

## 几何级数  [14:18–21:25]（t=858–1285）
- 概念：$1+a+a^2+\cdots=\frac1{1-a}$，**仅当** $|a|<1$。
- 关键推导/例题：$1+\frac12+\frac14+\cdots=2$ 的数轴图与芝诺悖论插曲（t=915–1034）；边界反例 $a=1$（$1/0$，“$\infty=\infty$ 半对”）、$a=-1$（在 0、1 间振荡，公式却给 $\frac12$）、$a=2$（左边 $\infty$ 右边 $-1$）（t=1081–1285）。（讲义对应：Geometric Series，讲义当场用 $S-aS=1$ 推公式；视频推迟到下一讲）
- 讲法特点：专挑公式“看起来能用”但其实发散的情形，强调先判收敛。

## 部分和与收敛定义  [21:26–23:46]（t=1286–1426）
- 概念：$S_N=\sum_{n=0}^N a_n$，$\sum_{n=0}^\infty a_n=\lim_{N\to\infty}S_N$；与反常积分同构。（讲义对应：Notation、Definition，讲义还指出 $a=1$ 时 $S-aS=1$ 变成 $\infty-\infty=1$，无意义）
- 学生可能的误区：t=1388 学生问几何公式怎么来——留到下一讲。

## $p$-级数：$\sum1/n^2$、$\sum1/n^3$  [23:47–27:54]（t=1427–1674）
- 概念：$\sum\frac1{n^2}$ 收敛（欧拉：$\pi^2/6$），$\sum\frac1{n^3}$ 收敛但无初等闭式（近年证明为无理数）；判敛和求值是两回事。（讲义对应：Another type of series）
- 讲法特点：承认 $\sum\frac1{n^p}\sim\int\frac{dx}{x^p}$ 里的 $\sim$ 是“一符两用”（t=1580），只表示“同类型的敛散问题”。
- 学生可能的误区：t=1629 学生以为这里的 $\sim$ 就是黎曼和的定义——不是；联系要靠 $\Delta x=1$ 的黎曼和。

## 调和级数：黎曼和夹逼  [27:55–34:29]（t=1675–2069）
- 关键推导/例题：上阶梯 $\int_1^N\frac{dx}x\le1+\cdots+\frac1{N-1}\le S_N$ ⇒ $S_N\to\infty$（t=1675–1907）；下阶梯 $S_N-1\le\ln N$（t=1908–2015）；合并 $\ln N<S_N<1+\ln N$。（讲义对应：Harmonic Series，图 ocw_figs/fig1_upper_riemann.png、ocw_figs/fig2_lower_riemann.png）
- 讲法特点：发散，而且知道发散得“像对数一样慢”。
- 学生可能的误区：t=2016 学生问下和那一步——矩形在曲线上方 ⇒ 和 ≥ 积分；在下方 ⇒ 和 ≤ 积分。

## 积分判别法（integral comparison）  [34:30–36:18]（t=2070–2178）
- 概念：$f>0$ 递减 ⇒ $\bigl|\sum_{n\ge1}f(n)-\int_1^\infty f\bigr|<f(1)$，两者同敛散；推出 $\sum n^{-p}$：$p\le1$ 发散、$p>1$ 收敛。（讲义对应：Integral Comparison）

## 极限比较  [36:19–39:09]（t=2179–2349）
- 关键推导/例题：$\frac1{\sqrt{n^2+1}}\sim\frac1n$ ⇒ 发散；$\frac1{\sqrt{n^5-n^2}}\sim n^{-5/2}$（从 $n=2$ 起）⇒ 收敛。（讲义对应：Limit comparison，讲义定义 $f/g\to c\in(0,\infty)$，例题为 $\frac1{\sqrt{n^2+10}}$、$\frac{n}{\sqrt{n^5-10}}$）
