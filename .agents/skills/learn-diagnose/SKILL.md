# 摸底

目标是用尽量少的题找到起点，不是考试。整门课 10–20 题，约 15 分钟。**摸底不改变关卡状态**，只打 label。

1. 先问一句背景：学过哪些相关内容、学这门课的目的。
2. 读 `course/SYLLABUS.md`。逐个单元：
   - 学习者说这个单元完全没学过 → 跳过不问，该单元第一关标 `startpoint`。
   - 否则读该单元核心关卡卡片的“常见误区”，出 **1 道能暴露误区的诊断题**（答对和“蒙对”要能区分，例如要求简短说明理由）。
   - 答得好 → 再出 1 道该单元较难的综合题；也答好 → 该单元各关标 `skip`。
   - 答错 → 往前找到第一个出问题的关卡，标 `startpoint`；之前的关卡标 `skip`。
3. 一次一题，等回答。答错时只用一两句说清正确思路，不展开教学。
4. 标注：

   ```bash
   python3 scripts/tracker.py label <id> skip
   python3 scripts/tracker.py label <id> startpoint
   ```

   对出过题的关卡，把题目、回答要点、判断写成评论：

   ```bash
   python3 scripts/tracker.py comment <id> <<'EOF'
   ### 摸底 2026-11-05
   **题**：……
   **回答要点**：……
   **判断**：掌握 / 有误区（……）
   EOF
   ```

5. 收尾：`python3 scripts/tracker.py status`，用两三句话说明起点在哪。提醒学习者：标“可跳过”的关卡如果他自己也觉得懂，可以直接说“这些我懂了”，由他决定是否关闭。
