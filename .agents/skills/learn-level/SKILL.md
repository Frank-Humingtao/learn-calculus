# 闯关

一个对话只打一关。

## 开场

1. 定关卡：学习者指定了就用（模糊描述就在 `course/SYLLABUS.md` 里找）；否则 `python3 scripts/tracker.py status` 推荐 2–3 关让他挑。
2. `python3 scripts/tracker.py show <id>`：读卡片和**历史评论**（上次学到哪、缺口、错因）。前置关卡没过就提醒一句，他坚持就照做。
3. `python3 scripts/tracker.py set <id> start`
4. 先问：“关于〈核心问题〉，你现在怎么想？”——从他已有的理解出发，而不是从零讲起。

## 学

按卡片“学习路径”给他选择（历史评论里有偏好就直接提议那一种）：

- **🎬 看视频**：`python3 scripts/clip.py <视频> <开始> <结束>` 切出片段并打开；给 2–3 个“看的时候注意”的问题。他看完回来再聊。需要时读 `course/frames/<名>/` 里该时间段的关键帧来对照板书。
- **📖 读原文**：给出文件和页码，附导读问题。讲解前自己先读 `course/extracted/` 中对应页。
- **💬 对话**：基于素材原文讲（先读对应的文字稿或页），小步推进，每步后让他动手做一小步。

讲解风格：默认先讲清楚再提问；他说“引导我”就改成苏格拉底式——用问题和提示让他自己推出来，不直接给答案。回复简短，一次只推进一个点。

## 复述与检查

1. 请他**用自己的话**回答核心问题、说说各条通关标准。你只补他缺的、纠正错的，不重复他已经说对的。
2. 出 2–3 道题检查（一次一题）：至少一道计算或应用、一道针对“常见误区”的概念判断。答错时先讲解，再**换一种形式**重问同一要点。

## 收尾

1. 问他：觉得懂了吗？**由他决定**：
   - 懂了 → `python3 scripts/tracker.py set <id> done`
   - 还没 → 保持进行中，下次换一条学习路径
   - 想之后再测 → 保持进行中，建议之后开新对话用 `learn-test`
2. 写记录（无论结果如何都写）：

   ```bash
   python3 scripts/tracker.py comment <id> <<'EOF'
   ### 闯关 2026-11-05
   **路径**：视频 18.01 L3 12:30–25:00 + 对话
   **起点理解**：……
   **复述缺口**：……
   **题目**：
   1. （题目全文）—— ✅ / ❌ 错因：……
   **学习者决定**：已掌握 / 继续 / 待测
   **下次建议**：……
   EOF
   ```

3. 用一句话说下一步建议，提醒下一关请开新对话。
